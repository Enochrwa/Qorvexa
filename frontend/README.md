# Frontend

React + TypeScript + Vite SPA for Qorvexa. Full guide: [docs/frontend/README.md](../docs/frontend/README.md).

Status: scaffold only; implemented in Sprint 0 and Sprint 1.

```
src/
  app/         providers, router, layouts
  features/    auth, profiles, home, browse, search, title, player, watchlist, account, admin
  components/  shared UI primitives
  lib/         API client and utilities
  hooks/       shared hooks
  styles/      Tailwind layers and tokens
  types/       shared and generated types
  test/        test utilities and MSW handlers
```
