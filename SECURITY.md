# Security policy

## Reporting a vulnerability

Please do **not** open a public issue. Use GitHub's private vulnerability reporting
(Security tab → "Report a vulnerability") or email the maintainer listed in the repository profile.
Expect an acknowledgement within 3 business days.

## Scope and rules

- Never commit secrets, tokens, `.env` files or media files. A credential pasted anywhere public or
  in chat is treated as leaked: revoke it immediately.
- Security design: [docs/security/security.md](docs/security/security.md).
