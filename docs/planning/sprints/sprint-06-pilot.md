# Sprint 6: Pilot readiness

**Goal:** a small, safe public pilot and an honest cost report for the customer.
**Dates:** 2027-01-13 to 2027-01-26

## Tasks

- [ ] Real-device test matrix: low-end Android, iPhone, laptop browsers, smart TV browser if relevant (L)
- [ ] Slow-network testing (3G/4G throttling) and data-saver mode verification (M)
- [ ] Publish Terms, Privacy, takedown contact; add report button flow ([legal](../../security/legal-compliance.md)) (M)
- [ ] Rights check: confirm the customer's authority for every uploaded title (S)
- [ ] Production deploy workflow with approval; custom domain if the customer funds it (M)
- [ ] Monitoring dashboards and alerts live ([monitoring](../../devops/monitoring.md)) (M)
- [ ] Usage and cost report: stored minutes/GB, delivered minutes, projected monthly cost at 2x and 10x usage (M)
- [ ] Admin training: short guide and screen recording for the studio (M)
- [ ] Bug bash and accessibility audit fixes (L)
- [ ] Pilot feedback form and analytics review plan (S)

## Acceptance criteria

- Pilot checklist in [deployment guide](../../devops/deployment-free-tier.md) fully ticked.
- Customer signs off the demo and receives the cost report.
- Rollback plan exists and has been rehearsed once.

## After the pilot

Review metrics against [vision](../../product/vision.md), re-rank the backlog, and decide on infrastructure upgrade (revisit ADR-0003).
