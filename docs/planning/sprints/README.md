## Ceremonies (solo-adapted)

- **Planning (30 min):** pick items from the [backlog](../backlog.md), confirm [Definition of Ready](../definition-of-done.md).
- **Daily log (5 min):** one line in the sprint file under "Log".
- **Review (30 min):** demo to the customer or record a short video.
- **Retro (20 min):** what went well, what to change, update the process.

T-shirt sizes: S (under 3 h), M (3-8 h), L (1-2 days), XL (split it).
