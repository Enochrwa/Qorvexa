# Feature roadmap and prioritization

Prioritization uses **value for viewers x value for the owner / effort**, then dependency order. See the sprint plan in [../planning/roadmap.md](../planning/roadmap.md).

## Launch (MVP pilot)

Accounts and profiles, catalog (movies, series, seasons, episodes), search and filters, home rows, watchlist, adaptive player with resume and next episode, admin studio with resumable upload and publish workflow, continue watching, rule-based recommendations, authorized MP4 downloads, rate limits, backups, error monitoring.

## Next

Ratings and reviews, mood collections and "surprise me", multiple audio tracks, chapters and seek thumbnails, drafts and scheduling polish, bulk metadata import, admin analytics, moderation queue, release notifications and calendar, social share with timestamps, playback diagnostics, private/signed playback URLs everywhere, accessibility audit fixes.

## Later

Browser offline library, casting, DRM, watch parties, semantic search, AI-generated summaries and chapters, native apps, subscriptions and payments, multi-tenant white-label.

## Release gating

A feature moves from Next to Launch only if the pilot data shows demand and the infrastructure budget is confirmed. Features that increase delivery or storage cost (higher resolutions, downloads, more renditions) require an updated cost estimate first.
