# Competitive analysis

These are design references, not claims that any service is best at everything. Details of other products change; re-verify before quoting them to the customer.

| Reference | Strong ideas to borrow | Gap Qorvexa can fill |
|---|---|---|
| Netflix | Personalized home, profiles, continue watching, auto-play next, row-based browsing | Give users control over recommendations and explain them; mood/theme discovery |
| YouTube | Speed control, captions, quality menu, keyboard shortcuts, chapters, timestamp links | Combine with curated movie metadata and resumable owner uploads |
| Disney+ | Franchise and collection organization, family profiles, clear season/episode navigation | Make "where am I in this series" effortless |
| Plex | Library management, metadata richness, watch status | Powerful admin studio for a single owner |
| Regional/local platforms | Mobile-data-friendly, local language content | Low-data mode, local language UI and subtitles |

## Takeaways

1. Home page speed and row relevance drive engagement more than the number of features.
2. Resume, next-episode and skip-intro remove friction; all three are launch requirements.
3. A data-saver mode (lower default quality, no autoplay previews) matters for East African mobile networks.
4. The admin experience is a differentiator for owner satisfaction.

## Opportunities to validate with the customer

- Local-language subtitles and UI.
- Low-data mode and mobile money payments (later).
- Curated collections by the owner (editorial voice).
